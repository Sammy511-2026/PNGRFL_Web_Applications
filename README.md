# PNG Rugby Football League

React and Vite frontend for the PNG Rugby Football League website.

## Development

Install dependencies and start the development server:

```powershell
npm install
npm run dev
```

The site is then available at the local URL shown by Vite.

## Checks

```powershell
npm run lint
npm run build
```

## Structure

- `src/pages` contains routed pages.
- `src/pages/admin` contains the admin access and dashboard screens.
- `src/Components` contains reusable UI components.
- `src/data` contains local fixture, ladder, league, and team data.
- `src/assets` contains logos and site imagery.
